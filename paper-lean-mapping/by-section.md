## Exact computation commands

Each program is listed once here; the result rows link to these entries. Run from the repository root. See [verification](../verification/README.md) for costs and coordinates.

### negative

Exact tangent witness and scalar error-budget arithmetic; not the analytic proof.

Command: `python3 verification/negative.py`.

Last line: `PASS: exact tangent witness and constants`.

Data: integer witness coefficients and constants are reconstructed in the script; no external data file.

### witness

Full-entry enclosure, independent rational convolution, coefficient budget, and threshold read from the manuscript.

Command: `python3 verification/witness.py`.

Last line: `PASS: manuscript witness, convolution, threshold, and five rejection controls`.

Data: integer witness coefficients and constants are reconstructed in the script; no external data file.

### positive

All polynomial identities and exact positive Gram certificates for the 48-step chain.

Command: `.venv/bin/python verification/positive.py`.

Last line: `PASS: F_N is SOS for 2 <= N <= 50; 48 exact steps; negative controls rejected`.

Data: [manifest.json](../verification/data/manifest.json); [step_02.json.gz](../verification/data/step_02.json.gz) through [step_49.json.gz](../verification/data/step_49.json.gz) (48 certificate files).
